## v0.0.139

NemoClaw v0.0.139 fixes rootless Podman cleanup for Hermes sandboxes and publishes compatible llama.cpp image signatures.

- Destroying a Hermes sandbox on rootless Podman now retries native-home cleanup as the image's pinned sandbox user when privileged cleanup cannot remove agent-owned files.
  If that cleanup fails, NemoClaw preserves the sandbox registry entry for a retry.
  Related change: [PR #13639](https://github.com/NVIDIA/NemoClaw/pull/13639).
- New llama.cpp image publications include Sigstore bundle signatures and a legacy image signature.
  The publication workflow verifies the legacy signature with Cosign 2 before it emits a receipt.
  Related change: [PR #13667](https://github.com/NVIDIA/NemoClaw/pull/13667).
